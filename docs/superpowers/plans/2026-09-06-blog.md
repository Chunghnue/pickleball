# Blog (Public Website) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the public-facing Blog feature described in `docs/01-website-khach-hang/08-blog.md` — a listing page with search/category filters and a per-post detail page — backed by a real API instead of the current `ComingSoon` placeholder.

**Architecture:** New `BlogModule` in `apps/api` (NestJS + TypeORM) exposing two public, unauthenticated endpoints (`GET /blog`, `GET /blog/:slug`) backed by a `blog_posts` table. `apps/web` gets two Next.js proxy routes and replaces the placeholder `/blog` page with a real list page plus a new `/blog/[slug]` detail page, following the same patterns already used by `/venues` and `/venues/[id]`.

**Tech Stack:** NestJS, TypeORM (Postgres), class-validator, Jest + Supertest (e2e), Next.js 16 App Router, React 19, Tailwind, lucide-react icons.

## Global Constraints

- Categories are a fixed set of 4, taken verbatim from the spec: `phan-mem` (Phần mềm), `kinh-doanh` (Kinh doanh), `xu-huong` (Xu hướng), `huong-dan` (Hướng dẫn). No admin UI for managing categories — they are a closed enum.
- Detail page URL shape is `/blog/<slug>` per the spec (e.g. `/blog/huong-dan-mo-san-pickleball-tu-a-den-z`).
- This spec file only covers the **public reader** experience (list, search, filter, detail). It says nothing about an authoring/admin UI — do not build one. Content is seeded directly (Task 3).
- All new backend code must follow existing conventions in `apps/api/src/courts` and `apps/api/src/page-views` (entities under `entities/`, DTOs under `dto/`, raw-SQL migrations, `whitelist: true` global `ValidationPipe` so DTOs must declare every accepted query field).
- All new frontend code must follow the existing `/venues` and `/venues/[id]` pages: `PublicHeader`/`PublicFooter` wrapper, green gradient hero section, Next.js API routes under `apps/web/src/app/api/**` that proxy to `API_BASE_URL` via `toNextResponse`.
- Read `apps/web/AGENTS.md` before touching any Next.js file — this repo pins a Next.js version with breaking API changes from what you may expect (e.g. dynamic route `params` is a `Promise`).

```ts
const WORDS_PER_MINUTE = 200;

export function computeReadingMinutes(content: string): number {
  const wordCount = content.trim().split(/\s+/).filter(Boolean).length;
  return Math.max(1, Math.round(wordCount / WORDS_PER_MINUTE));
}
```

```ts
// apps/api/src/blog/blog.service.ts
import { Injectable, NotFoundException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { FindOptionsWhere, ILike, Repository } from 'typeorm';
import { BlogPost } from './entities/blog-post.entity';
import { ListBlogPostsDto } from './dto/list-blog-posts.dto';

const DEFAULT_PAGE_SIZE = 9;
const MAX_PAGE_SIZE = 50;

export interface BlogPostsResult {
  items: BlogPost[];
  total: number;
  page: number;
  pageSize: number;
}

@Injectable()
export class BlogService {
  constructor(
    @InjectRepository(BlogPost)
    private readonly blogPostsRepository: Repository<BlogPost>,
  ) {}

  async list(dto: ListBlogPostsDto): Promise<BlogPostsResult> {
    const page = clampPage(dto.page);
    const pageSize = clampPageSize(dto.pageSize);

    const base: FindOptionsWhere<BlogPost> = {};
    if (dto.category) base.category = dto.category;

    const where: FindOptionsWhere<BlogPost> | FindOptionsWhere<BlogPost>[] = dto.query
      ? [
          { ...base, title: ILike(`%${dto.query}%`) },
          { ...base, excerpt: ILike(`%${dto.query}%`) },
        ]
      : base;

    const [items, total] = await this.blogPostsRepository.findAndCount({
      where,
      order: { publishedAt: 'DESC' },
      skip: (page - 1) * pageSize,
      take: pageSize,
    });

    return { items, total, page, pageSize };
  }

  async findBySlug(slug: string): Promise<BlogPost> {
    const post = await this.blogPostsRepository.findOne({ where: { slug } });
    if (!post) {
      throw new NotFoundException(`Bài viết với slug ${slug} không tồn tại`);
    }
    return post;
  }
}

function clampPage(raw?: string): number {
  const n = Number(raw);
  if (!Number.isFinite(n) || n < 1) return 1;
  return Math.floor(n);
}

function clampPageSize(raw?: string): number {
  const n = Number(raw);
  if (!Number.isFinite(n)) return DEFAULT_PAGE_SIZE;
  return Math.min(MAX_PAGE_SIZE, Math.max(1, Math.floor(n)));
}
```

```ts
// apps/web/src/app/api/blog/route.ts
import { NextRequest } from 'next/server';
import { API_BASE_URL } from '@/lib/api-config';
import { toNextResponse } from '@/lib/proxy-response';

export async function GET(request: NextRequest) {
  const params = new URLSearchParams();
  for (const key of ['query', 'category', 'page', 'pageSize']) {
    const value = request.nextUrl.searchParams.get(key);
    if (value) params.set(key, value);
  }
  const qs = params.toString();
```
